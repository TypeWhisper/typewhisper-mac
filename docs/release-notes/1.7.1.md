# TypeWhisper 1.7.1

## Keyboard and mouse stay responsive

Fixes a system-wide input freeze where typing stopped appearing and clicks barely
worked until TypeWhisper was quit ([#1513](https://github.com/TypeWhisper/typewhisper-mac/issues/1513)).

TypeWhisper watches the keyboard for its hotkeys before other apps receive the
keys. Until now every keystroke waited for TypeWhisper's main thread, so when that
thread stalled, input across the whole Mac stalled with it. macOS then switched the
hotkey listener off, and TypeWhisper switched it straight back on into the same
stall.

- Hotkey matching now runs on its own thread. If TypeWhisper does not pick up a
  keystroke within 100 ms, the keystroke goes straight to the app you are typing in.
  A hotkey check that has already started gets up to another half second.
- While TypeWhisper is unresponsive, keys reach your apps right away. Hotkeys pressed
  in that time take effect once TypeWhisper responds again.
- If macOS switches the listener off repeatedly for being too slow, TypeWhisper
  waits before turning it back on instead of re-enabling it right away.
- Diagnostic logs now record how long TypeWhisper stopped responding.
