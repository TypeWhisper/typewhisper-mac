# Unreleased

- Dictation: Dictating into the kitty terminal no longer ends with "No text field detected" when kitty shows the text a moment late. kitty passes typed text on to the shell, which echoes it back, so a field that has not changed yet does not mean the text went nowhere. TypeWhisper now counts the dictation as inserted there, as it already does for web inputs.
- Parakeet 1.7.0 (requires TypeWhisper 1.8.2): **Import Model…** in the plugin settings adds your own Parakeet TDT models converted to Core ML, from a folder or a Hugging Face repository, for example a fine-tune for one language. Raw `.mlpackage` conversions are compiled during the import. Fine-tunes that add tokens to the vocabulary, such as the Greek Parakeet v3 fine-tune, transcribe correctly. Imported models appear in the model list and can be deleted there.
- Dictation: With a cloud engine that cannot stream, such as Microsoft AI, Groq or ElevenLabs, the live preview no longer uploads the last 10 seconds of audio again every 3 seconds, which sent about three times the audio of each dictation. With Live preview engine set to Match dictation engine, the preview now runs on a loaded local engine that streams your language, such as Apple Speech, while the final text still comes from your dictation engine. Without such an engine no preview is shown, unless live text in the text field or the Live Transcript window is on; these keep using the cloud engine then. To keep the previous behavior, choose your cloud engine under Settings > Appearance > Live preview engine.
- HTTP API: `verbose_json` responses can include the time of each word. Send `timestamp_granularities[]=word` (as in OpenAI's API) to get a `words` array with `word`, `start` and `end` in seconds; `/v1/transcribe/local-file` takes `"timestamp_granularities": ["word"]`. Responses without the parameter stay unchanged. Engines that report word times, such as Parakeet and ElevenLabs, fill it.
- ElevenLabs 1.1.0: Dictations of up to 30 seconds in Auto mode return in under a second instead of about 15 seconds. The plugin waited for ElevenLabs to close the finished realtime session; it now ends the session as soon as the transcript arrives. Transcriptions through the ElevenLabs batch API now keep Scribe's word timestamps. `verbose_json` API responses get segments split at sentence ends and pauses instead of an empty `segments` list, and word timestamps when requested. Speaker detection aligns ElevenLabs transcripts by word as well. Short realtime dictations report word timestamps and, with automatic language detection, the detected language. The new **Scribe v2 Medical** model, tuned for clinical audio at the Scribe v2 price, transcribes in batch. A saved selection of the deprecated Scribe v1 moves to Scribe v2. The detected language is reported with the two-letter code TypeWhisper uses (`de` instead of `deu`), so German and other language-specific formatting applies with automatic detection. Javanese, Asturian, Cebuano, Irish, Igbo, Kabuverdianu, Kurdish, Kyrgyz, Ganda, Luo, Northern Sotho, Odia, Umbundu, Wolof, Xhosa and Zulu can be selected; Hawaiian and Volapük, which ElevenLabs rejects, are no longer offered. Realtime errors whose type does not say "error", such as `rate_limited`, `quota_exceeded` or `invalid_request`, now switch to the batch API at once instead of after an eight-second wait. When an API key's own credit quota is used up, the error now shows ElevenLabs' message instead of "Invalid API key".
