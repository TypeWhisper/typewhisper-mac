# Unreleased

- Term packs: Import your own packs from a JSON file in the community pack format with Import Term Pack... under Dictionary > Term Packs > Local Packs, turn them on and off like the other packs, and export them for another Mac. Importing an edited file with the same id replaces the pack after asking. Local packs stay on this Mac: TypeWhisper does not review, sync or update them, and they cannot take over the id of a built-in or community pack. Files with invalid JSON, missing fields or no terms and corrections are rejected with a message that names the problem.
- Recorder: Settings > Recorder > Recordings Folder sets where new recordings are saved, for example a folder outside iCloud Drive. Recordings you already have stay where they are, and the Recorder keeps listing the earlier folder until you remove it there. If the chosen folder is unavailable, for example on a disconnected disk, a recording is saved to the default folder instead and the Recorder says so. The App Store edition keeps access to the chosen folder after a restart.
