TypeWhisper for Mac 1.8.0 is the first macOS version of this app record. It is a universal purchase with the existing iPhone and iPad app.

TypeWhisper is a menu bar app. On first launch the setup assistant opens. No account is needed for any free feature.

Basic dictation:
1. Complete the setup assistant and allow microphone access.
2. Speech engine: on Apple silicon the setup assistant offers to activate Parakeet, which downloads its model once. On macOS 26 or later, Apple Speech also works without a download. Model downloads contain model weights only, no executable code.
3. Open TextEdit, press Option-Space, speak, then press Option-Space again. The transcription is inserted into TextEdit.

Optional permissions:
- Accessibility: used only to post Cmd-V so the transcription is pasted into the frontmost app (and Cmd-C to copy selected text for the prompt palette, Return for the optional Auto Enter setting). TypeWhisper does not read other apps' content through the Accessibility API. Without this permission the text is copied to the clipboard and a notice asks the user to press Cmd-V.
- Input Monitoring: only needed for Fn, modifier-only, double-tap, and mouse-button shortcuts, and for cancelling with Esc while another app is active. Regular shortcuts such as Option-Space work without it.
- Calendars: only for the optional meeting reminders and automatic meeting recording.
- Local network: only when the user enables pairing so their own iPhone or iPad can use this Mac for transcription.

Integrations:
All integrations shown on the Integrations page are first-party plugins bundled and signed inside the app. Nothing is downloaded or loaded from outside the app bundle. Cloud speech and language providers are optional and require the user's own API key. The local HTTP API is off by default and only accepts connections on 127.0.0.1.

Premium:
Open Settings > Premium to see the localized monthly and lifetime offers and Restore Purchases. These are the same in-app purchases as in the iOS app. Buying and restoring only need the Apple Account; Sign in with Apple is optional and only connects devices for cloud sync. Premium features: meeting automation, speaker detection, cloud sync of dictionary and snippets, and use of this Mac from a paired iPhone or iPad.

Existing TypeWhisper license:
Customers who already own a TypeWhisper license can connect it in Settings > Premium > Connect Existing TypeWhisper License after Sign in with Apple. The license key is entered only on a TypeWhisper web page (app.typewhisper.com) in the system web authentication sheet, never in the app, and activates this Mac as one device of that license. This is access to a purchase made outside the app under guideline 3.1.3(b); the same Premium features are offered as in-app purchases, and the app shows no prices or links to buy outside the App Store. The iOS app offers the same button.
