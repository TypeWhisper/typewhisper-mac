# Unreleased

- Workflows: With Apple Intelligence, Email Reply, Meeting Notes, Cleaned Text, Checklist and Summary now write the result in the language you dictated. Their prompts are English, and the on-device model often answered German dictations in English, mostly when the engine reports no language, as Parakeet does with Spoken Language on Auto. TypeWhisper now recognizes the language from the dictated text when needed and asks for the result in that language. In our test, 21 of 40 German dictations stayed German before and 40 of 40 after. Workflows with fine-tuning, custom workflows and Translation keep following their own language instructions.
- Reson8 1.2.1, AssemblyAI 1.2.0, Microsoft AI 1.1.0, Mistral AI 1.3.1 and Meta 1.1.0 (require TypeWhisper 1.8.3): With speaker diarization on, dictations no longer ask the provider to label speakers, which they bill on top of the transcription and TypeWhisper never shows in dictated text. Recordings, file transcriptions, watch folders and the HTTP API still get the labels. In a test with Reson8, a seven-second dictation with live preview sent three requests with diarization before and none after. Dictations with AssemblyAI now use the Sync API instead of the async one while diarization is on. Plugin SDK: `PluginSpeakerLabels.areRequested` tells an engine whether the host uses speaker labels for the current transcription.
- Local LLM (MLX) 1.0.8, Qwen3 ASR 1.1.16, Granite Speech 1.2.2, Voxtral 1.0.21 and Canary ASR 1.1.2: The plugins use swift-transformers 1.4.0, which updates yyjson to 0.13.0 and fixes a stack buffer overflow with crafted JSON files larger than 4 GiB (GHSA-f4vc-345x-4mvm). Local LLM keeps the spaces Gemma models write before punctuation, so `x != y` no longer turns into `x!= y` and `a .gitignore file` no longer into `a.gitignore file`.
- Microsoft AI 1.1.0: An optional backup endpoint, with its own API key, takes over when Azure Speech refuses a request for lack of capacity in the first region. On HTTP 429, a 5xx status or no answer in time, TypeWhisper sends the same request to the backup right away, without waiting for the first region's Retry-After, and only when both fail does Automatic Fallback take over. Use a Speech resource in another region that offers MAI Transcribe; the settings warn when it does not.
- Mistral AI 1.3.0 (requires TypeWhisper 1.8.1): Dictations with a live preview now stream to Voxtral Mini Transcribe Realtime 3, so the preview shows Mistral's text while you speak. When you stop, the transcription model writes the final text: it heard dictations more accurately than the realtime model, and in our tests the text was there 0.3 to 0.4 seconds after the stop. A new Transcription setting shows both ways with Mistral's list prices: Live ($0.69 per hour of audio with Voxtral Mini Transcribe 3, $0.72 with Small, since both models are billed) and After recording ($0.21/h or $0.24/h), which shows no preview from Mistral. Recordings and files always use the transcription model. Dictionary terms reach Mistral as context, in live sessions and file transcriptions, which fixes names such as "Voxtral" and "Reson8". Speaker labels mark who is speaking in recordings with several people. The language picker offers the 58 languages Mistral lists for Transcribe 3 instead of 8. The model lists come from your Mistral account once the plugin settings loaded them, and then refresh in the background once a day, so new models appear without a plugin update, Mistral Medium 3.5 among them. Workflows and the plugin settings can pick how much Mistral Large 4 (low, medium or high, low by default), Mistral Small 4 and Medium 3.5 (off or high, off by default) reason before they answer. Rejected requests show Mistral's explanation instead of the raw response.
- Mistral AI 1.2.0: Transcription uses Voxtral Mini Transcribe 3 by default and Voxtral Small Transcribe 3 for the higher-quality model. Both send the recording to Mistral's transcription API. A saved Voxtral 2 model, or a short Transcribe 3 name, switches to the matching Transcribe 3 model. The language models are Mistral Large 4, Mistral Small 4 (the default) and Ministral 3 in 14B, 8B and 3B. A saved older Mistral, Pixtral or Ministral model switches to its current replacement, and any other saved model stays. With no language pinned, the transcript reports the language Mistral detected.
- AssemblyAI 1.2.0 (requires TypeWhisper 1.8.1): Dictations with Universal-3.5 Pro now stream to AssemblyAI while you speak. The live preview, live text in the text field and the Live Transcript window show AssemblyAI's own transcript, and the final text comes from the same connection: in our tests a 10-second dictation was ready 0.2 seconds after it stopped instead of 3.2. Recordings, file transcriptions and dictations without a live session use AssemblyAI's new Sync API, which returns the text in one request instead of uploading, queueing and polling; a 3-second dictation took 0.2 seconds instead of 3.0, and 7 minutes of audio took 2 seconds. A new Transcription setting shows the three ways with AssemblyAI's list prices: Live ($0.45 per hour the connection is open), Sync ($0.30/h) and Async ($0.21/h, the previous behavior). Live streams dictations that show a live preview; recordings, files and dictations without a preview use the Sync API. Sync and Async show no live preview from AssemblyAI, so their listed rate is what they cost, apart from add-ons such as dictionary terms or speaker labels. If a live session cannot start, for example beyond the 5 new sessions per minute of a free AssemblyAI account, or the Sync API fails, TypeWhisper transcribes the recording with the next API. Speaker diarization and Universal-2 still use the async API, and with more than 100 dictionary terms or a term longer than 50 characters the final text of a live dictation comes from the recording, which uses all of them and is billed in addition to the live connection.
- Stop recording after silence: an engine that recognizes when you finished speaking can end a toggle dictation after half the silence duration, at least one second. A pause in the middle of a sentence still waits the full duration, and speaking on restores it. Plugin SDK: engines opt in through the Objective-C method `setLiveTranscriptionTurnEndHandler:`, so their plugins stay loadable by older versions.
- Reson8 1.2.0 (requires TypeWhisper 1.8.1; ending dictations early needs this TypeWhisper version): End dictation when you finish speaking uses Reson8's turn detection, which tells a finished thought from a pause in the middle of a sentence. With Stop recording after silence on, a toggle dictation then stops after half the silence duration, at least one second. While the option is on, the live preview shows your words at pauses rather than while you speak.
- Reson8 1.1.0 (requires TypeWhisper 1.8.1): The model picker offers Rumble-2-Flash, Reson8's fast model for prerecorded audio in 45 languages, next to Resonant-1 and your custom models, which run on Resonant-1. The list comes from Reson8, so a new model appears after Refresh, and the languages and live streaming follow the selected model. Dictations with Resonant-1 now stream to Reson8 while you speak: the live preview, live text in the text field and the Live Transcript window show Reson8's transcript as it arrives, instead of a local engine's or one that uploads the last seconds again every few seconds. The final text comes from the same connection, in our tests about 0.3 seconds after a short dictation stopped; if the connection fails, TypeWhisper transcribes the whole recording as before. Recordings, file transcriptions and dictations without live preview now go to Reson8's prerecorded endpoint, which costs 1 credit per minute instead of 2 and in our tests finished a 72-second recording in 0.9 seconds instead of 2.0; Advanced settings switch them back to realtime, which shows the text while it arrives. A new Filler words setting leaves words such as "um" out of the transcript, keeps them as spoken, or leaves the choice to the model as before. With several languages selected, Reson8 detects the language of each utterance among them, and transcripts report the language it detected. Dictionary terms reach Reson8 as phrases, up to 250 per request, and Advanced settings adjust how strongly they and custom models steer recognition. With Keep dictionary in a custom model, TypeWhisper keeps the dictionary in a custom model in your Reson8 account instead and updates it when the dictionary changes, so Reson8 uses up to 50,000 terms. Pattern sets describe structured tokens such as order codes, for example AMZ[0-9]{6}; each set appears as a model, so a profile or workflow can use it where such tokens are spoken, and Check with Reson8 tests the patterns. Transcripts include word timestamps and sentence segments, which subtitles, the Recorder and speaker detection use. Speaker diarization lets Reson8 label who spoke when, up to eight speakers: with Detect Speakers on, recordings and file transcriptions use these labels instead of detecting speakers on the Mac, and dictated text stays without labels. Recordings longer than five minutes are labelled in five-minute parts, and while the option is on, transcripts arrive after the recording instead of streaming. Rumble-2-Flash does not take filler words, dictionary terms, timestamps or speaker labels, and its settings show only what it supports. Reson8's credit limit and concurrent connection limit now show Reson8's own message.
- Soniox 1.2.15: Dictation and file transcription use Soniox STT v6 (`stt-rt-v6`, `stt-async-v6`), which Soniox released on November 3, 2026; it retires v5 on December 15, 2026. A model list saved before v6 refreshes in the background when TypeWhisper starts, so **Automatic (Latest)** moves to v6 without pressing **Refresh**, and a pinned v5 model moves to **Automatic (Latest)**. In the TypeWhisper benchmark, real-time v6 makes fewer errors than v5 in English (5.6 % vs. 6.9 % WER), German (5.0 % vs. 5.5 %) and Russian (5.4 % vs. 6.3 %) and places punctuation better. v6 writes amounts with the currency as a word, for example "850 dollars" and "578.000 Euro" instead of "$850" and "578.000 €".
- ElevenLabs 1.2.0 (requires TypeWhisper 1.8.1): In Auto mode, Scribe v2 dictations now stream to ElevenLabs while you speak. The live preview, live text in the text field and the Live Transcript window show ElevenLabs' own transcript again, instead of a local engine's or none, without uploading the audio a second time. The final text comes from the same session and is ready about 0.3 seconds after you stop; in our tests a 10-second dictation took 0.3 seconds instead of 0.9, a 44-second one 0.3 seconds instead of 1.3. Dictations longer than 30 seconds stream as well instead of going to the batch API after the recording; the session commits in speech pauses about every 20 to 30 seconds. With active dictionary terms the final text still comes from the batch API, which uses the terms, because ElevenLabs' realtime API often wraps the transcript in quotation marks with them; these dictations are billed for realtime and batch when a live preview is shown. If the realtime session fails, TypeWhisper transcribes the whole recording as before. Scribe v2 Medical and REST only still transcribe after the recording, and their preview runs on a local engine.
- Watch folders: The Markdown transcript now starts with frontmatter that names the audio file, its word timestamps, the date, length, language, engine and speakers, and the text has a paragraph per speaker turn that starts with its time and speaker, for example `**[00:12:03] Speaker 1:**`. With an engine that reports word timestamps, `<file>.timestamps.json` next to the audio file holds them in the format of the HTTP API's `verbose_json` (next to the transcript when the audio file is deleted afterwards). Tools that cut audio by its transcript, such as the TypeWhisper scripts for REAPER, find a recording and the times of its words from a note in an Obsidian vault.
- Recorder: Recordings transcribed with an engine that reports word timestamps get `<recording>.timestamps.json` next to them; deleting a recording moves it to the Trash with the other files.
- Obsidian 1.3.0: Recorder notes name the recording and its word timestamps in their frontmatter (`audio:`, `timestamps:`) and show its length.
