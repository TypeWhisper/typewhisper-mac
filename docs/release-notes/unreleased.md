# Unreleased

- Term packs: Import your own packs from a JSON file in the community pack format with Import Term Pack... under Dictionary > Term Packs > Local Packs, turn them on and off like the other packs, and export them for another Mac. Importing an edited file with the same id replaces the pack after asking. Local packs stay on this Mac: TypeWhisper does not review, sync or update them, and they cannot take over the id of a built-in or community pack. Files with invalid JSON, missing fields or no terms and corrections are rejected with a message that names the problem.
- Recorder: Settings > Recorder > Recordings Folder sets where new recordings are saved, for example a folder outside iCloud Drive. Recordings you already have stay where they are, and the Recorder keeps listing the earlier folder until you remove it there. If the chosen folder is unavailable, for example on a disconnected disk, a recording is saved to the default folder instead and the Recorder says so. The App Store edition keeps access to the chosen folder after a restart.
- Workflows: The built-in workflow instructions follow your dictation more reliably on local and cloud models. Cleaned Text now also removes filler words such as "um" and "ähm", stutters and repeated words, keeps only the final version when you correct yourself, and splits run-on speech into sentences. Translation drops filler words too and only cleans up text that is already in the target language. Email Reply writes directly to the person in dictations like "tell Tom that …" and ends with a closing instead of a "[Your Name]" placeholder. Meeting Notes stay in the language of the dictation, headings included, and keep every date. A workflow's fine-tuning still takes priority, so "Keep filler words; only fix punctuation" or "Write the summary in English" brings back the behavior you want.
- Inline Commands: A spoken instruction such as "translate this into English" now changes the output language instead of keeping the language of the dictation.
- Prompts: New installs get a Translate preset that reliably translates German text and a Draft Email preset that no longer invents details. Prompts you already have keep their text.
- Local LLM (MLX) 1.0.6: The model list recommends a model for this Mac based on its memory, describes each Gemma 4 model, and warns when a model needs more memory than the Mac has. On a fresh install the recommended model is preselected. Gemma 4 E4B (8-bit) is no longer experimental. Gemma 4 26B-A4B stays experimental because it does not load yet, and its load error no longer suggests deleting the downloaded model.
- Language Detection (new plugin): When you select several spoken languages and the engine accepts only one, such as Parakeet, WhisperKit, Qwen3 or Groq, the plugin detects which of them you speak instead of always using the first one. It runs on your Mac in about 15 ms per transcription, and the audio never leaves it. Install it from Discover plugins; the App Store edition includes it. Live previews still use the first selected language.
- Canary, Cohere Transcribe (Local) and Google Cloud STT 1.1.0: These engines cannot detect the spoken language themselves. With Auto-detect all languages and the Language Detection plugin enabled, the plugin now picks the language among theirs. Until now Canary and Cohere Transcribe stopped with an error, and Google Cloud STT used its default language code. Dictation settings explain this under Auto-detect all languages.
- Canary and Cohere Transcribe (Local): With Auto-detect all languages, these engines no longer stop with an error when nothing picks the language, for example when the Language Detection plugin is unsure on a short dictation, is not enabled, or hears a language the engine does not support. They now use the first of your preferred languages in System Settings > General > Language & Region that they support, and only stop with the error when they support none of them. Google Cloud STT 1.1.1 keeps using its default language code in these cases.
- Parakeet 1.6.1: Using another Parakeet model for a single transcription, as the local API's `model`, the CLI's `--model` or a workflow with its own Parakeet model do, now waits for that model to load. Until now it failed with "Cloud provider not configured. Please set an API key." Nemotron 3.5 ASR Streaming no longer drops the first and last words of files and other recordings it transcribes after they end; live dictation stays as fast as before. Parakeet 1.6.1 requires TypeWhisper 1.8.1 or later.
- Dictation: Dictating into GNU Emacs or a remote desktop client such as Parsec no longer ends with "No text field detected". These apps draw their own content and report only their window to Accessibility, so TypeWhisper cannot tell whether the text arrived and no longer warns there.
- Dictation: Dictating into a new message in Apple Mail no longer ends with "No text field detected" although the text arrived. The same applies to other editors where the whole web page is editable. Accessibility does not show their text changing, so TypeWhisper no longer takes that as a missed text field. Web pages without a text field still get the warning.
- Granite Speech 1.1.0: Adds IBM's Granite Speech 5.0 models. Granite 5.0 TurboCTC (470M, about 950 MB) is the new default: it transcribes English, French, German, Spanish, Portuguese, Italian and Japanese with punctuation and capitalization in a few milliseconds per sentence, but cannot translate or use dictionary terms. Granite 5.0 2B (about 4.6 GB) also writes punctuated text and translates, and it uses your dictionary terms. If you already use a Granite 4.0 model, it stays selected; Granite 4.0 remains available. With TurboCTC selected, the Recorder and file transcription hide the Translate to English task, and a request to translate returns an error that names the models that can. Translation now works while dictionary terms are active. Until now Granite received the terms as its whole instruction and transcribed instead of translating. The terms are now passed as keywords after the transcribe or translate instruction, as the model expects.
- Canary 1.1.1, Qwen3 1.1.15, Voxtral 1.0.20 and Local LLM (MLX) 1.0.7: Each of these plugins brings its own copy of Apple's MLX framework. With several of them enabled, one plugin could end up running code from another plugin's copy, which can crash TypeWhisper during a transcription or text processing. Each plugin now uses only its own copy, as Granite Speech 1.1.0 already does.
- Granite Speech 1.2.0: Translate lets you choose the target language. In the Recorder, file transcription and dictation recovery, choosing Translate with Granite 5.0 2B or Granite 4.0 shows a Target language picker with English, French, German, Spanish, Portuguese, Japanese, Italian and Chinese. English is the default, the task picker names the chosen language, and each place remembers its choice. Until now Granite translated into the selected spoken language, so German speech with German selected came back in German although the task said Translate to English. The local API's `target_language` with `task=translate` now goes straight to Granite when it supports that language, without Apple Translate. Granite translates best to and from English; Italian and Chinese are meant for English speech. With older TypeWhisper versions, Granite translates as before.
