TypeWhisper `1.7.0` is the stable `1.7` macOS release. It adds iCloud sync for History and Inbox, a visual keyboard for shortcuts, new dictation indicator themes, undo for the last dictation, Dictation Recovery, and custom local model import, along with fixes across hotkeys, cancellation, Bluetooth audio, and text formatting.

## Highlights

- Added iCloud synchronization for History and Inbox, with a redesigned History that groups entries by device and supports filtering and search.
- Added a visual Mac keyboard for configuring shortcuts. Key labels follow the active macOS input source, and the editor shows shortcut conflicts and unavailable keys.
- Added Classic, Glass, and Light dictation indicators, with a live preview on the new Appearance settings page.
- Added Undo Last Dictation and Restore Raw Transcript to the menu bar and as configurable global hotkeys. Both replace the inserted text directly and leave the clipboard untouched. They are rejected with feedback when the target field or caret changed.
- Added Dictation Recovery: the last three successful dictations are kept for up to 24 hours, so an incomplete provider response can be retried even when it looked successful. The Immediately retention setting disables this buffer.
- Added file transcription from Finder and optional web-media transcription through the Web Link plugin.
- Added import of compatible speech models from a Hugging Face repository or a local folder in the settings of local plugins, and added the Canary ASR plugin.

## Dictation and shortcuts

- Added spoken submit, per-dictation submit with Enter, Inline Commands, and a paste-last-transcription action.
- Added configurable cancellation with double Escape, single Escape, immediate cancellation, or cancellation disabled.
- Escape used to cancel dictation is now consumed by TypeWhisper instead of reaching the target app. Escape works normally again after cancellation.
- Fixed lost Stop hotkeys. Modifier-only shortcuts recover after event-monitor interruptions without swallowing the next Stop press.
- Added an opt-in hedge to Automatic Fallback: when the primary engine has not answered within a configurable threshold, the same audio is also sent to the recovery engine and the first result wins. A dispatched race costs one extra API call.
- Bounded the final-transcription phase with a deadline, and let dictation start when the recovery engine is the only ready engine.
- TypeWhisper now explains why dictation cannot start and links to the fix.
- Improved recognition of short, quiet dictations in aggressive mode.
- Improved Bluetooth microphone handling, media pause and resume around recording, and audio-engine teardown.
- The setup wizard now distinguishes selected, installed, loaded, and tested models. Setup completes only when the current engine can transcribe and both permissions are granted; incomplete setup offers Finish Later.

## Text handling and workflows

- Number formatting now offers Always, 10 and above (the default), and 100 and above under Settings → Dictation → Output Formatting. Smaller spoken whole numbers and ordinals keep their wording. The threshold also applies when a workflow enables number normalization.
- Dictionary corrections now apply before workflow LLM processing, and workflows share vocabulary. Long dictations can be processed in segments.
- Added vocabulary import from Wispr Flow, Handy, and compatible CSV files, with clearer feedback for unsupported formats.
- Snippet triggers now require word boundaries.
- German clock times are written with a colon, English month and day phrases are normalized, and the final period after standalone dictated values is handled correctly.
- Auto-submit is skipped when raw text is inserted after an LLM failure.

## History, data, and administration

- Windows dictation and Recorder entries appear as their own History sources.
- Recorder rows offer a copy-transcript action, and recent transcriptions are grouped in a workflow palette submenu.
- Added export and deletion of all app data in Advanced settings.
- Administrators can provision `ManagedLicenseKey` through a macOS configuration profile or user-context script. TypeWhisper activates it automatically and shows organization-managed licensing controls. See the [MDM deployment guide](https://github.com/TypeWhisper/typewhisper-mac/blob/v1.7.0/docs/mdm/README.md).
- Final-transcription diagnostics include audio duration, word counts, and segment timing without logging audio, prompt contents, or transcript text.
- Settings use the native macOS sidebar.

## Models and integrations

- Groq no longer sends dictionary terms by default. In tests with German dictations, the term list made Whisper Large V3 skip most of some dictations, while the same audio without terms came back complete. Settings you changed yourself are kept, and dictionary corrections after transcription still apply. You can turn terms back on under Groq → Send dictionary terms.
- Added the Vercel AI Gateway plugin for transcription and LLM processing through one API key.
- Added native Ollama model discovery to OpenAI-Compatible profiles.
- Renamed the Gemma 4 plugin to Local LLM with a new plugin ID, and added Qwen3.5 and LFM2.5 models.
- Added the Confucius4-R2T2 community transcription plugin.
- Added a Local and Cloud filter to Discover, and a free-disk-space check before local model downloads.
- Plugins can now provide their own pages and use authenticated command-line tools as providers.
- Fixed Parakeet restore after automatic model unload, Deepgram Nova-3 language selection, replacing a stored OpenAI API key, and Soniox realtime dictation without a visible preview. OpenRouter retries long audio as chunks.
- Corrected HTTP API target-language translation and session ownership.

## Performance

- Reduced work during startup, History rendering and sync, statistics updates, sound playback, and the path from stop to text insertion.
- Made the audio input callback realtime-safe.

## Compatibility and distribution

- Requires macOS 14.0 or later and supports Apple silicon and Intel Macs.
- Every release includes the iCloud bridge.
- New plugin releases from the 1.7 source line require TypeWhisper 1.7.0 or later. Existing compatible plugin releases remain available to 1.6 hosts. This app release does not republish plugins.
- Stable `1.7.0` builds use the default Sparkle channel; release candidates and daily builds remain on their preview channels.
- Improved Simplified Chinese wording.
- Built with Xcode 26.6 and Swift 6.3, with updated Swift dependencies.

Release validation is tracked in the [TypeWhisper 1.7.0 checklist](https://github.com/TypeWhisper/typewhisper-mac/issues/1439).
